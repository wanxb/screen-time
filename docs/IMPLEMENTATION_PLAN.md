# Screen Time 开发实施计划

## 阶段 1：核心统计

- 前台软件识别。
- 空闲检测。
- 今日总时长、连续时长、应用时长累计。
- 本地 JSON 读写和原子写入。

## 阶段 2：屏幕时间看板

- 主窗口概览卡片。
- 每日/每周趋势图。
- 应用时长列表。
- 分类统计。

## 阶段 3：提醒辅助能力

- 连续使用提醒调度。
- 半透明全屏提醒窗口。
- 提醒形象和托盘提醒动画。
- 可配置提醒间隔、休息时长、关闭行为。

## 阶段 4：系统体验

- 系统托盘菜单。
- 最小化到托盘。
- 开机自启动。
- 主题切换。
- 发布构建。

## 当前命名

工程、命名空间、产物和文档统一使用 ScreenTime / Screen Time / 屏幕时间。
