# Windows 屏幕时间 PRD v0.1

## 1. 产品名称

中文名：屏幕时间
英文名：Screen Time

## 2. 产品定位

屏幕时间是一款 Windows 桌面端轻量工具，核心目标是记录和呈现用户在不同软件上的活跃使用时长。休息提醒是辅助功能，用于在连续使用过久时给出温和、明显、可配置的提醒。

第一版强调：先把“今天用了多久、每个软件用了多久、连续用了多久”记录准确，再用提醒帮助用户及时休息。

## 3. MVP 范围

必做：
- 软件级屏幕时间统计：识别当前前台软件，并在用户活跃时累计时长。
- 今日总使用时长、连续使用时长、软件使用排行。
- 每日 JSON 本地存储，不上传数据。
- 休息提醒：达到连续使用阈值后显示半透明全屏提醒。
- 设置页：提醒开关、提醒间隔、休息时长、空闲阈值、主题、托盘行为、提醒形象。
- 系统托盘常驻：打开看板、设置、退出，并可显示提醒形象动画。

不做：
- 不做网站级统计。
- 不读取键盘内容、聊天内容、文件正文或浏览器 URL。
- 不截图、不录屏、不上传。
- 不做强制锁机、家长控制、管理员守护进程。
- 不做账号系统和云同步。

## 4. 核心用户流程

1. 用户启动 Screen Time。
2. 应用创建默认设置和今日统计文件。
3. 主窗口显示今日使用、连续使用、下次休息、运行状态、趋势图和应用时长列表。
4. 应用在后台按活跃输入状态累计当前前台软件的使用时长。
5. 达到连续使用阈值时，显示休息提醒。
6. 用户可关闭、稍后提醒或确认去休息。
7. 统计数据持续保存在本机 `%AppData%/ScreenTime/`。

## 5. 功能细节

### 5.1 屏幕时间统计

统计粒度为 Windows 软件/进程级别。每个软件记录：
- 软件名
- 进程名
- 可执行路径
- 今日活跃秒数
- 首次使用时间
- 最后使用时间
- 分类

用户空闲超过设置阈值后暂停累计。默认空闲阈值为 60 秒。

### 5.2 连续使用统计

连续使用时长用于触发休息提醒。用户活跃时增加，空闲或完成休息后重置/暂停。

默认值：
- 提醒间隔：50 分钟
- 休息倒计时：5 分钟
- 遮罩透明度：35%

### 5.3 休息提醒

提醒层使用半透明全屏窗口，背景仍可见。中心显示：
- 标题：休息一下吧
- 说明：看看远处，放松眼睛，顺便活动一下肩颈。
- 倒计时
- 提醒形象
- 操作按钮：关闭、稍后提醒、我去休息了

当“允许提前关闭提醒”关闭时，提醒层隐藏操作按钮并等待倒计时结束。

### 5.4 设置

设置项包括：
- 开启休息提醒
- 连续使用多久后提醒
- 休息倒计时时长
- 允许提前关闭提醒
- 无输入多久后视为空闲
- 软件主题
- 提醒形象：小猫 / 小狗
- 提醒遮罩透明度
- 启用托盘提醒动画
- 最小化到系统托盘
- 开机自启动

## 6. 数据存储

目录：

```text
%AppData%/ScreenTime/
  settings.json
  app_categories.json
  usage/
    YYYY-MM-DD.json
  sessions/
  assets/
  icon-cache/
```

示例设置字段：

```json
{
  "version": 1,
  "reminder_enabled": true,
  "reminder_interval_minutes": 50,
  "break_duration_minutes": 5,
  "allow_close_fullscreen_reminder": true,
  "reminder_character": "cat",
  "idle_threshold_seconds": 60,
  "overlay_opacity": 0.35,
  "launch_at_startup": false,
  "minimize_to_tray": true,
  "tray_reminder_animation_enabled": true
}
```

## 7. 技术方案

- 语言：C#
- 桌面框架：WPF
- 目标框架：.NET 8 Windows
- 系统能力：Win32 API / PInvoke
- 存储：本地 JSON 文件
- 项目名：ScreenTime
- 命名空间：ScreenTime

关键 API：
- `GetForegroundWindow()` 获取当前前台窗口。
- `GetWindowThreadProcessId()` 获取进程。
- `GetLastInputInfo()` 判断空闲状态。

## 8. 验收标准

- 今日总使用时长准确增加。
- 每个软件的使用时长准确累计。
- 空闲期间不累计时长。
- 重启应用后能读取已有统计。
- 连续使用达到阈值后弹出提醒。
- 设置保存后立即生效，并能持久化。
- 数据只保存在本地 `%AppData%/ScreenTime/`。
- 项目文件、命名空间、可执行文件和文档均使用 Screen Time / 屏幕时间命名。
